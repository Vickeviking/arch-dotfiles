# C essentials

## Types and sizes (x86-64 Linux)

| Type | Size | Note |
| ---- | ---- | ---- |
| `char` | 1 | signed or unsigned depending on the platform; use `signed char` / `unsigned char` for numbers |
| `short` / `int` | 2 / 4 | |
| `long` / `long long` | 8 / 8 | `long` is 4 on Windows |
| `float` / `double` | 4 / 8 | |
| pointer, `size_t` | 8 | `size_t` for sizes and indices, `ptrdiff_t` for pointer differences |
| `int8_t` … `uint64_t` | exact | `<stdint.h>`: use these when the size matters |
| `bool` | 1 | `<stdbool.h>` (a keyword since C23) |

Print them right: `%zu` for `size_t`, `PRIu64` from `<inttypes.h>` for `uint64_t`, `%p` for pointers.

## Declarations read inside out

| Declaration | Means |
| ----------- | ----- |
| `int *p` | pointer to int |
| `const int *p` | pointer to a const int (can't write through it) |
| `int *const p` | const pointer to int (can't repoint it) |
| `int a[10]` | array of 10 ints |
| `int *a[10]` | array of 10 pointers to int |
| `int (*a)[10]` | pointer to an array of 10 ints |
| `int (*f)(int)` | pointer to a function taking int, returning int |
| `typedef int (*cmp_fn)(const void *, const void *);` | name for that function pointer type |

## Structs, unions, enums

```c
struct point { int x, y; };
struct point p = { .x = 1, .y = 2 };          // designated initializers
typedef struct node { int val; struct node *next; } node_t;

union value { int i; float f; };              // all members share the same bytes
enum color { RED, GREEN = 5, BLUE };          // BLUE == 6, enums are ints
```

## The preprocessor

| Directive | Does |
| --------- | ---- |
| `#include <x.h>` / `"x.h"` | system header / your own header |
| `#define N 64` | text substitution, no type |
| `#define MAX(a, b) ((a) > (b) ? (a) : (b))` | parenthesize everything; arguments may be evaluated twice |
| `#ifndef X_H` / `#define X_H` / `#endif` | include guard (or `#pragma once`) |
| `#ifdef DEBUG` … `#endif` | conditional compilation (`-DDEBUG`) |
| `static_assert(sizeof(int) == 4, "…")` | compile-time check (C11) |

## Strings

- A string is a `char` array ending in `'\0'`. `strlen` doesn't count it; buffers need room for it.
- Prefer `snprintf(buf, sizeof buf, …)` over `sprintf`, and `strncpy` only knowing it may not terminate.
- `strcmp(a, b) == 0` for equality, never `a == b` (that compares pointers).

## Undefined behavior to keep in mind

| UB | Example |
| -- | ------- |
| signed overflow | `INT_MAX + 1` (unsigned wraps, signed is UB) |
| out-of-bounds access | `a[10]` on `int a[10]` |
| using freed or uninitialized memory | reading a local before assigning it |
| null dereference | `*p` with `p == NULL` |
| unsequenced modification | `i = i++ + 1;` |
| strict aliasing | reading a `float` through an `int *` (use `memcpy`) |

`-fsanitize=address,undefined` catches most of these at run time (see Build & debug).

## Concurrency (C11 / POSIX)

```c
#include <pthread.h>
pthread_t t;
pthread_create(&t, NULL, worker, arg);
pthread_join(t, NULL);

pthread_mutex_t m = PTHREAD_MUTEX_INITIALIZER;
pthread_mutex_lock(&m); /* … */ pthread_mutex_unlock(&m);

#include <stdatomic.h>
atomic_int counter = 0;
atomic_fetch_add_explicit(&counter, 1, memory_order_relaxed);
```

OpenMP: `#pragma omp parallel for` with `-fopenmp`. `gK` on `omp_get_thread_num` opens its libgomp manual.
