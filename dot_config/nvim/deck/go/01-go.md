# Go

## Basics

```go
package main

import ("fmt"; "os")

func main() {
	x := 42                          // declare and infer
	var name string = "hej"          // explicit; zero value if omitted ("" here)
	nums := []int{1, 2, 3}           // slice
	ages := map[string]int{"li": 2}  // map
	for i, n := range nums { fmt.Println(i, n) }
	if v, ok := ages["li"]; ok { fmt.Println(v) }
	fmt.Fprintln(os.Stderr, x, name)
}
```

Zero values: `0`, `""`, `false`, `nil` for pointers, slices, maps, channels, interfaces, functions.

## Slices

| Expression | Does |
| ---------- | ---- |
| `make([]int, len, cap)` | new slice |
| `s = append(s, x)` | add; may reallocate, so always reassign |
| `s[a:b]` | view sharing the same array (changes show through) |
| `copy(dst, src)` | copy elements, returns the count |
| `slices.Sort(s)`, `slices.Contains(s, x)` | helpers (Go 1.21+) |

A slice is a header: pointer, length, capacity. Same shape as a Rust `Vec`, but shared and garbage collected.

## Structs, methods, interfaces

```go
type Point struct{ X, Y float64 }

func (p Point) Len() float64 { return math.Hypot(p.X, p.Y) }   // value receiver: gets a copy
func (p *Point) Scale(k float64) { p.X *= k; p.Y *= k }        // pointer receiver: can modify

type Shape interface{ Area() float64 }    // satisfied implicitly by any type with Area()
```

	return fmt.Errorf("open config: %w", err)     // %w wraps, so callers can inspect

## Goroutines and channels

```go
results := make(chan int, 10)          // buffered channel
var wg sync.WaitGroup
for _, job := range jobs {
	wg.Add(1)
	go func() { defer wg.Done(); results <- work(job) }()
}
go func() { wg.Wait(); close(results) }()
for r := range results { fmt.Println(r) }

select {
case msg := <-in:
	handle(msg)
case <-time.After(time.Second):
	fmt.Println("timeout")
case <-ctx.Done():
	return ctx.Err()
}
```

`sync.Mutex`, `sync.RWMutex`, `sync.Once`, `atomic.Int64`, and `context.Context` for cancellation.

## Tooling

| Command | Does |
| ------- | ---- |
| `go mod init example.com/app` | new module |
| `go run .` / `go build` | run / build |
| `go test ./...` / `go test -run Name -v` | all tests / some tests |
| `go test -race ./...` | race detector |
| `go vet ./...` / `golangci-lint run` | static checks (golangci-lint runs in nvim) |
| `go get pkg@latest` / `go mod tidy` | add / clean dependencies |
| `go test -bench . -benchmem` | benchmarks |
| `go tool pprof cpu.out` | profiler |
